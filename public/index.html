Hey, welcome aboard! 🎷

This is a small intro/demo site — three pages of plain HTML, CSS and vanilla JS, built to show off a lightweight deployment pipeline running on Azure App Service.

What is this?

ns-vse-webdev is a tiny static site served by a minimal Express server. No frameworks, no build step — just HTML, CSS and JS files served straight up. It exists mainly to demonstrate a clean, secretless CI/CD pipeline from GitHub to Azure.
